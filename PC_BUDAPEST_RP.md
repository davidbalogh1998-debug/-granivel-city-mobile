# Granivel City — Budapest RP PC

A PC-only Budapest RP fejlesztés a `pc/` mappában található.

- Valós Budapest koordinátarendszer és streamelt OSM-alapú világ
- Mapzen/AWS domborzat
- PC input, autók, NPC-k, rendőrség, körözés, küldetés, RP state
- Offline BudapestData csomag támogatás
- Nagy asset pack külön SSD mappából is betölthető a `GRANIVEL_BUDAPEST_DATA` környezeti változóval

A több tíz GB generált asset nem kerül normál Git history-ba; ehhez Git LFS vagy külső object storage szükséges.
