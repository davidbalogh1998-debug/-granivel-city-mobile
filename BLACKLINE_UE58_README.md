# BLACKLINE — Unreal Engine 5.8 AAA Vertical Slice

Ez az ág (`blackline-ue58-v0.1`) a korábbi Safari/Granivel City prototípustól elkülönített natív Unreal projekt fejlesztési ága.

## V0.1 elkészült rendszerek
- third-person karakter és kamera
- mobil touch joystick, kamera swipe, ACT/FIRE/RUN/BRAKE HUD
- vezethető autó és be-/kiszállás
- lövés
- 1–5 szintű wanted/heat rendszer
- wanted szinttel skálázódó rendőri üldözés
- civil NPC-k
- runtime generált Veyra városi blockout
- utak, járdák, épületek, rooftopok, utcai világítás
- nappal/éjszaka, atmoszféra és post process
- NIGHT RUN kezdő küldetés
- cash/HUD/objective marker
- high-end iOS render profil
- saját PBR SourceArt pipeline (asphalt/concrete/brick/sidewalk/glass)

## Fontos
A V0.1 egy AAA-ready vertical slice **alap**, nem kész fotórealisztikus AAA játék. A végleges fotórealizmushoz riggelt high-fidelity hero karakter, mocap/motion matching, részletes járművek, környezeti assetek és LOD/HLOD tartalom szükséges. Nem használ GTA/Rockstar asseteket.

A teljes V0.1 projektcsomag a ChatGPT munkamenetben `BLACKLINE_UE58_V0.1.zip` néven készült el; a következő fejlesztési mérföldkő a hero character + részletes Meridian városrész + eső/vizes utak.
